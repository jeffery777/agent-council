# Requirements: wordcount

| ID | Requirement |
| --- | --- |
| REQ-1 | `count_words(text)` returns the number of words in `text`. Words are separated by whitespace. |
| REQ-2 | An empty string, or a string of only whitespace, has zero words. |
| REQ-3 | `count_lines(text)` returns the number of lines in `text`. An empty string has zero lines. A final line without a newline still counts. |
| REQ-4 | `longest_line(text)` returns the length of the longest line in `text`, without the line ending. An empty string gives 0. A final line without a newline still counts. |
| REQ-5 | `count_file(path)` returns the number of words in the UTF-8 text file at `path`. |

Anything not listed here is out of scope.
