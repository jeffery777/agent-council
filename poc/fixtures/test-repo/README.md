# poc-testrepo

A disposable test repository for the agent-council M1 PoC.

- It exists only on the local machine and has no remote.
- Its content is a small example written for the PoC. It contains no private
  data, no credentials and no code from a real project.
- It is generated by a script and can be deleted and rebuilt at any time.

## Layout

| Path | Content |
| --- | --- |
| `docs/requirements.md` | The requirements of the example. |
| `src/wordcount.py` | The example module. |
| `tests/test_wordcount.py` | Tests for the example module. |

## Run the tests

```bash
python3 -m unittest discover -s tests
```
